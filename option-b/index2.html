Filters are contextual: each tab exposes the slicers that belong to its dataset. Mailing rates use the simple-average method (mean of the per-mailing percentage columns) so they reconcile with the source file by hand. Theme and topic use any-match logic — an item carrying several tags counts under each one, so tag totals exceed the item count. Click tracking is a cumulative export with no date dimension.
